## Essential instructions when planning and attempting code changes

Read and follow the linked instructions when planning and making changes.

| Instructions | Description |
|--------------|-------------|
| [Writing good code](instructions/writing-good-code.instructions.md) | Design for longevity, integrate with existing code, and consider refactoring and maintenance. Important. |
| [Comments and doc strings](instructions/comments-doc-strings.instructions.md) | Keep comments and doc strings sparse, brief, and focused on the code rather than the history of a change. |
| [Writing docs](instructions/writing-docs.instructions.md) | Distinguish agent and human documentation, choose appropriate locations, and confirm proposed documentation with the user. |
| [Updating docs](instructions/updating-docs.instructions.md) | Keep documentation current when changes warrant it, and confirm large documentation updates with the user. |
